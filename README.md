# JavaScript Projects

A collection of JavaScript projects and exercises created while developing my front-end programming skills.

These projects explore interactive web development, DOM manipulation, event handling, forms, game logic, user input, Ajax, jQuery, and JavaScript fundamentals.

## Featured Projects

### 🍕 Pizza Menu

An interactive pizza-ordering application built with JavaScript, HTML, and CSS.

The project allows users to select pizza sizes and toppings while JavaScript processes the selections and calculates the order.

[View Pizza Menu](Pizza_Project/)

---

### ❌⭕ Tic Tac Toe

A browser-based Tic Tac Toe game built with JavaScript, HTML, CSS, images, and supporting media assets.

The project demonstrates interactive game logic and dynamic user input.

[View Tic Tac Toe](Tic-Tac-Toe/)

---

### 🧮 Calculator

A functional browser-based calculator built with JavaScript, HTML, and CSS.

The project provides an interactive interface for performing common arithmetic operations.

[View Calculator](Calculator_Project/)

---

### ✅ Todo App

A simple task-management application built with JavaScript, HTML, and CSS.

The project demonstrates dynamically updating page content based on user interaction.

[View Todo App](Todo_App/)

## Running the Projects

Clone the repository:

```bash
git clone https://github.com/joeyfarruggia/javascript-projects.git
cd javascript-projects
```

Most projects are browser-based and can be run by opening their main HTML file.

For example:

```text
Pizza_Project/Pizza.html
Tic-Tac-Toe/TicTacToe.html
Calculator_Project/calculator.html
Todo_App/index.html
```

No server is required for most of the projects.
